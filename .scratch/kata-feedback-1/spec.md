# Kata — feedback round 1 (after first device use)

Changes asked after the first real use of v1. Each ticket is one change.

## Decisions

- Info about an exercise must be reachable wherever I choose or see an exercise: the add-exercise picker, and each step of a routine.
- Custom steps get optional written details (how-to text) I can edit, shown wherever an exercise's info is shown.
- Owner mode is about custom exercises, not drawing import: it lists the custom exercises in use so the owner can promote them into the shipped catalog, and keeps the drawing request prompt for exercises that need a new drawing. Importing or replacing drawings in the app is removed (shipped drawings come from the code).
